## الوظائف والتكامل

- اليوم الافتراضي هو تاريخ المتصفح المحلي. يدعم اختيار أي يوم ضمن نطاق التواريخ الحالي، والتنقل للأمام والخلف وعبر حدود الشهر والسنة والسنوات الكبيسة. يحفظ `?day=` التاريخ المختار بعد refresh وعند العودة من Tasks؛ التاريخ غير الصالح في الرابط يعود لليوم المحلي.
- يجلب `GET /api/tasks?date=...` المهام الخاصة باليوم، ويقسمها حسب الحالة. يستخدم Start وComplete فقط `PATCH /api/tasks/:id` لتغيير status يدويًا. يظل الخادم المرجع الوحيد للملكية وقواعد الحالة والتعارض.
- تبقى المهام المكتملة محفوظة، وتُستعاد حالتها بعد refresh.
- يعرض Timeline الوقت والعنوان والحالة بترتيب start_time، وتعرض المهام غير المؤقتة في قسم مستقل. العرض مشتق من السجلات نفسها ولا يُنشئ نسخًا أو يكتب أوقاتًا أو تواريخ.
- الإضافة الاختيارية والتعديل والحذف المؤكد تعيد استخدام وظائف المرحلة الثانية. لا تتغير قواعد التحقق. يدعم العرض التحميل والفراغ وفشل التحميل وإعادة المحاولة والنجاح وأخطاء الأفعال.
- لا endpoints أو جداول أو migrations أو اعتماديات جديدة. لا AI أو جدولة تلقائية أو سلوك متعلق بالمزاج.
