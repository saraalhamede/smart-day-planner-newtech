## الوظائف والتكامل

يعرض Calendar أيام الشهر الصحيحة بترتيب ثابت الاثنين–الأحد، مع أشهر سابقة وتالية ومدخل شهر وزر This month. يدعم حدود السنة والسنوات الكبيسة وحدود نطاق التاريخ الحالي. يبدأ بالشهر المحلي الحالي ما لم يكن هناك تاريخ محدد مسبقًا في المخطط أو الرابط؛ عند تغيير الشهر يُختار اليوم الأول منه.

تظهر أعداد المهام على التواريخ عبر الحالات كلها. يختار النقر اليوم ويعرض ملخصه، ويفتح Open Daily Planner اليوم نفسه لإدارة المهام. الواجهة لا تحتوي أفعال إنشاء أو تعديل أو حذف أو تغيير حالة. يدعم Tab وEnter/Space كسلوك أزرار أصلي، وأسهم الأيام والأسابيع وHome/End مع نقل التركيز عبر حدود الشهر.

رُفع التاريخ المشترك إلى App وأُعيد استخدام `day=YYYY-MM-DD`، مع `view=calendar|planner|tasks` لاستعادة العرض بعد refresh والدخول. بقيت خصائص Daily Planner الحالية وعقود API كما هي. لا routing library جديدة.

الجلب الوحيد الخاص بالتقويم هو **GET /api/tasks** الموجود والموثق بالجلسة؛ يعزل الخادم المالك قبل إعادة القائمة. لأن API لا يدعم نطاق شهر، تُصفى القائمة في العميل لهذا MVP الصغير. التجميع للعرض فقط: لا POST أو PATCH أو DELETE من Calendar، ولا تغيير للتواريخ أو الأوقات أو الحالات أو الأولويات، ولا جداول أو endpoints جديدة.
