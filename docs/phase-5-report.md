## الوظائف وتدفق البيانات

تظهر **All Tasks** بوضوح وتشمل جميع تواريخ المستخدم الحالي. البطاقات: Total Tasks وCompleted Tasks وIn Progress Tasks وWaiting Tasks. كل سجل API يساهم مرة واحدة في حالته؛ المجموع يساوي جمع الحالات الثلاث، ويشمل المكتمل. Completion Rate = Completed / Total × 100، مقربة إلى منزلة عشرية، و`0.0%` عند الفراغ. شريط progress أصلي له تسمية ميسرة ونص نسبة مقروء.

التدفق: MySQL → استعلام Tasks الحالي المقيد بـ`req.user.id` من جلسة الخادم → `GET /api/tasks` مع cookies من المصدر نفسه → hook الصفحة → حساب حالات المهام → البطاقات والنسبة. لا معرف مستخدم من العميل، ولا mock أو localStorage، ولا POST أو PATCH أو DELETE من Dashboard. لا endpoints أو جداول أو اعتماديات جديدة، ولا تغيير لعقود API أو قواعد المهام.

فتح الصفحة أو Refresh Dashboard يجلب البيانات الحالية؛ العودة بعد إدارة المهام تعيد الجلب. توجد حالات التحميل والفراغ والخطأ/Retry وانتهاء الجلسة، ويحفظ URL عرض Dashboard والتاريخ المشترك بعد refresh. تبقى المصادقة وCRUD وDaily Planner وCalendar كما هي.
